# ayywi

This package only runs the CLI. The design system is **[@danitesler/ayywi](https://www.npmjs.com/package/@danitesler/ayywi)**; install that one in your app.

```sh
npx ayywi lint
npx ayywi init
npx ayywi brand "#0ea5e9" --name acme
```

Same as `npx @danitesler/ayywi …`. Docs: https://github.com/danitesler/ayywi
